# Data inventory (28.09.2026; reminders 14.10.2026)

| Data | Personal? | Stored where | Encrypted | Retention | Leaves the phone? |
|---|---|---|---|---|---|
| Chat text | Yes (whatever the user types) | App memory, and History (below) | — | Until the app closes; History 30 days | Only to OpenAI when the user chose ChatGPT |
| ChatGPT access/refresh token | Yes | `noBackupFilesDir/vault` | Tink + Keystore | Until sign-out / delete everything | Sent to OpenAI to authenticate |
| Account id, plan type, masked email | Yes | Same vault file | Tink + Keystore | Same | No |
| Flagged reports | Yes | Vault | Tink + Keystore | Last 50, until delete everything | No (delivery channel decided before launch) |
| Voice audio (ChatGPT voice) | Yes | Not stored | — | Only while talking | Streamed to OpenAI under the user's account while a ChatGPT voice conversation is on |
| Voice captions and the call's transcript | Yes | App memory, and History (below) | — | Until the conversation stops; History 30 days | Recent lines go to ChatGPT with a question the voice hands over |
| History (the user's words and WatchGPT's replies, voice and chat) | Yes | `noBackupFilesDir/memory`, own Keystore key | Tink + Keystore | 30 days (at most 300 conversations, 3,000 turns), until deleted in History or delete everything; off switch in History | The last conversations of two days and the facts go to ChatGPT at the start of each conversation, cleaned; turns only Gemma heard (marked local) never |
| Facts the user asked WatchGPT to keep | Yes | Same vault file | Tink + Keystore | Until forgotten (by voice or in History), at most 100 | With every conversation, to ChatGPT |
| Screen of the app in front (accessibility, when a tool asks) | Yes (chats, emails, whatever it shows) | Not stored | — | One look | Labels of controls to ChatGPT; content only to Gemma on the phone |
| Apps WatchGPT can use | Package names the user turned on; Gemma's answer per app version (money, secrets or other) | `shared_prefs/app_limits*` | Private app storage | Until delete everything | No |
| Notes | Yes (whatever the user asks to note) | `noBackupFilesDir/notes`, own Keystore key | Tink + Keystore | Last 500, until deleted in the app or delete everything; sign-out keeps them | Only to ChatGPT, when the user asks to add or read notes |
| Calendar events (read) | Yes | The phone's calendar (Android calendar provider), with the user's permission | Android | The user's calendar | Only when the user asks about their agenda (`list_calendar_events`): with "Private things stay on this phone" (default) answered on the phone; switched off, to ChatGPT after `Redactor`. Events added by voice are WatchGPT items (next row), not written to this calendar |
| Reminders and agenda items (`organizer.db`) | Yes (titles, notes, times, repeats) | `noBackupFilesDir/organizer.db` on the phone and on the watch | Each item AES-256-GCM with an Android Keystore key, its id bound as authenticated data. Not encrypted: the row id and revision columns, delivery receipts (item id and the time of the alert that rang), calendar links (event id, revision, a hash of the copy) and sync counters | Until deleted. A deletion keeps a record with only id, revision and a random device id, without content, with no expiry, so an offline device can't restore the item | To the other device through the Wear Data Layer (next row). To Google Calendar only with calendar sync on (row after). Listed by voice only when asked (`list_reminders`, `list_calendar_events`), with the same private-on-phone rule as calendar events; what the user says to add one goes to ChatGPT |
| Wear Data Layer copies of reminders | Yes (same content as above) | Google Play services' Data Layer storage, on the phone and on the watch | Not by WatchGPT: plain JSON, including deletion records (which keep no content) | The latest version of each item; WatchGPT never removes them, a deleted item's copy is replaced by its deletion record | Between the two WatchGPT apps (same id and signing key), directly or relayed through Google's servers |
| Google Calendar copies (only with calendar sync on) | Yes (title, notes, time, repeat) | The Google calendar the user owns and chose, through the Calendar Provider | Google | Until the item is deleted or a one-off completed while sync is on, or Delete everything; copies stay when sync is turned off or another calendar is chosen | To Google under the user's account, as private events without calendar alerts |
| Timers and alarms | No | The phone's clock app, or the watch's | — | Clock app | No |
| Watch microphone for "Hey Watch G P T" (or the user's own phrase) | Yes (sound near the watch) | Watch memory only | — | 100 ms at a time, while a window is open (30 s after the screen comes on, or always if the user switches that on) | No; after the phrase, a conversation starts |
| Learn my voice takes | Yes (the user's voice) | Watch memory only | — | Until learned, then dropped | No |
| Learned spellings | Yes (derived from the user's voice) | Watch SharedPreferences | Android file encryption | Until Forget my voice, Change phrase, delete or reinstall | No |
| The user's own wake phrase and its spellings | Low (what the user typed) | Watch SharedPreferences | Android file encryption | Until changed back to "Hey WatchGPT", delete or reinstall | No |
| Messages from notifications | Yes (senders' names and texts) | Phone memory (`MessageInbox`); banking, payment, password manager and authenticator apps skipped (`SensitiveApps`) | — | At most 6 h and 40 messages, gone with the notification or the app | With "Private things stay on this phone" (default): no. Gemma answers on the phone (`GemmaReader.answer`) and the phone says it (`LocalSpeech`, offline voice) or shows it in the chat; ChatGPT gets only "the phone is telling the user". Switched off: to ChatGPT after `Redactor` (codes, cards, IBANs, passwords, keys, links, numbers, emails) |
| Contacts | Yes (names, numbers) | The phone's contacts (read only) | Android | Not copied | The chosen name and number type go to ChatGPT with the request; the number goes only to the carrier |
| Pending message or call | Yes | Phone memory (`Pending`) | — | 2 min, or until the user says yes, no or stop | No |
| Speech of private answers (`LocalSpeech`) | Yes (what the phone says) | A WAV in the app's cache while it's made | — | Deleted as soon as it's read (seconds) | No: Android's speech engine with a voice that needs no network |
| What WatchGPT did (`ActionLogStore`) | Low (tool name, level, outcome, time; no content, no names) | `noBackupFilesDir/log`, own Keystore key | Tink + Keystore | 30 days, last 1000; clear in the app or delete everything | No |
| Texts and calls the user confirmed | Yes | The phone's SMS and call history | Android | The phone's history | To the other person through the carrier |
| Places and app names | Yes (whatever the user asks) | Not stored (the pop-up's last 8 maps in memory) | — | Until the app closes | To Google Maps or the opened app, on the phone; for the pop-up's map, the place name to OpenStreetMap (Nominatim, then map tiles), with the phone's IP address |
| Voice timings (debug builds) | No (timings and event types only) | App external files dir | — | Manual | Only via `adb pull` by the developer |
| WatchGPT Plus state (`Plus`) | Pseudonymous (RevenueCat's anonymous app user id) | RevenueCat SDK cache on the phone | Android file encryption | Until uninstall | To RevenueCat at app start (entitlement, prices) and with a purchase or restore; no conversation data |
| Chosen WatchGPT (Plus) | No (a number) | SharedPreferences | Android file encryption | Until delete everything | No (the seed goes to the watch) |
| Settings (opt-ins, notice accepted) | No | SharedPreferences | Android file encryption | Until delete everything | No |
| GPU-broken flag | No (device model string) | SharedPreferences | — | Until delete everything | No |
| Model file | No | `noBackupFilesDir/models` | — (public file, integrity-checked) | Until deleted | No |
| Benchmark files (debug builds) | No (synthetic prompts, timings only) | App external files dir | — | Manual | Only via `adb pull` by the developer |
| ML Kit diagnostics (opt-in) | Pseudonymous (install id) | Google | Google | Google's terms | Yes, to Google |
